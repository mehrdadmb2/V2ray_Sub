# 📥 نحوه استفاده از Subscription

Subscription در واقع یک URL است که کلاینت شما با استفاده از آن لیستی از کانفیگ‌ها را دریافت و به‌روزرسانی می‌کند.

### مهم‌ترین نکته

خود URL را با `https://` کامل کپی کنید؛ مثلاً:

```text
https://raw.githubusercontent.com/mehrdadmb2/V2ray_Sub/refs/heads/main/Mix.txt
```

**URL را داخل یک مرورگر هم می‌توانید باز کنید** تا محتوای خام فایل را ببینید، اما برای استفادهٔ معمول باید URL را داخل Client وارد کنید.

# 📱 V2rayNG — Android

**Repository:**

https://github.com/2dust/v2rayNG

**Releases:**

https://github.com/2dust/v2rayNG/releases

V2rayNG یکی از کلاینت‌های رایج Android برای V2Ray/Xray است.

### انتخاب فایل APK

در Releaseها معمولاً معماری فایل در نام آن مشخص می‌شود.

| فایل | مناسب برای |
|---|---|
| `arm64-v8a.apk` | اکثر گوشی‌های Android جدید |
| `armeabi-v7a.apk` | دستگاه‌های ARM قدیمی‌تر |
| `x86.apk` | برخی شبیه‌سازها / دستگاه‌های x86 |
| `x86_64.apk` | دستگاه‌ها یا شبیه‌سازهای x86_64 |
| `universal.apk` | سازگاری عمومی‌تر، معمولاً با حجم بیشتر |

**برای اکثر گوشی‌های امروزی، ابتدا `arm64-v8a` را بررسی کنید.**

### بررسی Release رسمی

[🔗 V2rayNG Releases](https://github.com/2dust/v2rayNG/releases)

> در صفحهٔ Release رسمی، علاوه بر APKها ممکن است فایل‌های `.sig`، کلید GPG و Source Code هم وجود داشته باشد. برای نصب عادی APK را انتخاب کنید و فایل‌های Signature/Source را با APK اشتباه نگیرید.

# 🛠 اجرا و توسعهٔ محلی

ساختار UI پروژه برای اجرا به‌صورت Static طراحی شده است و می‌توان آن را با یک HTTP server ساده اجرا کرد.

### روش ساده

```bash
git clone https://github.com/mehrdadmb2/V2ray_Sub.git
cd V2ray_Sub
```

سپس یک Static Server اجرا کنید.

### Python

```bash
python -m http.server 8080
```

و سپس:

```text
http://localhost:8080
```

> اجرای سایت با HTTP server محلی برای بررسی مسیر فایل‌ها و تصاویر نسبت به باز کردن مستقیم `file://` مناسب‌تر است.

# 🧯 رفع اشکال

## Subscription لود نمی‌شود

این موارد را بررسی کنید:

```text
1. اینترنت فعال باشد
2. URL دقیقاً با https:// شروع شود
3. URL را بدون کوتاه‌کنندهٔ لینک استفاده کنید
4. در صورت خطای موقت GitHub چند ثانیه بعد دوباره Update کنید
```

برای Mix از این URL استفاده کنید:

```text
https://raw.githubusercontent.com/mehrdadmb2/V2ray_Sub/refs/heads/main/Mix.txt
```

---

## کانفیگ‌ها نمایش داده نمی‌شوند

اگر از نسخهٔ وب استفاده می‌کنید:

- صفحه را Refresh کنید.
- Cache مرورگر را بررسی کنید.
- DevTools → Console را بررسی کنید.
- مستقیم URL `Mix.txt` را باز کنید و ببینید پاسخ دریافت می‌شود یا خیر.

# 🔒 امنیت و حریم خصوصی

این پروژه یک رابط/مدیر Subscription و نمایش‌دهندهٔ فایل‌های عمومی GitHub است.

### نکات مهم

- هیچ Password، Token یا Credential شخصی را داخل URL Subscription قرار ندهید.
- فقط لینک‌هایی را استفاده کنید که به آن‌ها اعتماد دارید.
- قبل از اجرای فایل‌های دانلودی، منبع Release را بررسی کنید.
- در صورت وجود SHA-256 در Release رسمی، مقدار فایل را با آن مقایسه کنید.
- Signatureها را با APK/ZIP اصلی اشتباه نگیرید.

---

# ⚠️ نکات مهم دربارهٔ Subscription

Subscription با کانفیگ منفرد یکسان نیست.

### Subscription

```text
URL → چندین کانفیگ
```

### Single Config

```text
vless://...
vmess://...
trojan://...
ss://...
```

بنابراین:

- برای Subscription، URL فایل را وارد کنید.
- برای کانفیگ تکی، همان URI را Import/Copy کنید.
