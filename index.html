🛠 راه‌اندازی اولیه | Getting Started ⚙️

# 1️⃣ دانلود و نصب
git clone https://github.com/mehrdadmb2/V2ray_Sub.git
cd V2ray_Sub

# 2️⃣ نصب پیش‌نیازها
pip install -r requirements.txt

# 3️⃣ اجرای برنامه
python v2ray_sub_manager.py

📲 راهنمای اضافه کردن اشتراک به V2rayNG (اندروید) 📱

مراحل زیر را به‌ترتیب دنبال کنید:

1️⃣ اجرای V2rayNG
2️⃣ منوی اشتراک‌ها
3️⃣ افزودن اشتراک جدید
4️⃣ وارد کردن اطلاعات
5️⃣ به‌روزرسانی
✅ اشتراک اضافه شد! 🎉

💡 نکته: همیشه اشتراک‌های خود را به‌روزرسانی کنید تا از سرورهای فعال استفاده کنید. 🔄
